# Playwright AI Agentic API Automation Framework

An AI-assisted, configuration-driven API Test Automation Framework built with Playwright, GitHub Copilot, and GitHub Actions.

The framework uses business requirements, API contracts, and test data as inputs to generate, execute, and maintain reusable API automation while following modern DevOps practices.

## Features

- AI-assisted API automation using GitHub Copilot
- Configuration-driven framework
- Playwright API Testing
- DummyJSON API automation
- Authentication token management
- Reusable API client architecture
- Business requirement-driven testing
- API contract-driven testing
- Externalized test data
- HTML reporting
- GitHub Actions CI/CD
- Automatic execution on every push
- Manual workflow execution
- Scalable architecture for future Jira, Swagger and Postman integrations

## Technology Stack

- Playwright
- TypeScript
- Node.js
- GitHub Copilot
- GitHub Actions
- DummyJSON API
- VS Code
